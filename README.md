# TDE 1 – Git e GitHub

## 📌 Sobre este repositório

Este repositório foi criado como parte da **TDE 1 (Trabalho Discente Efetivo)** da disciplina, com o objetivo de aprender e praticar os conceitos fundamentais do **Git** e **GitHub**, incluindo:

- Versionamento de projetos
- Commits organizados e mensagens descritivas
- Uso de branches para novas funcionalidades
- Pull Requests e merges
- Documentação com README
